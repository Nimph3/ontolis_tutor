# OntoTutor 8.0 — свободное исследование графа знаний

Обновление по результатам проверки учебной сессии. **Оформление, цветовая гамма, графический редактор и CSS не менялись**. Изменены серверная логика учебного диалога и тексты подсказок интерфейса.

## Исправления

1. **Определения больше не обрезаются до 230 символов.** При объяснении соседнего понятия выводится полный текст из атрибута загруженной онтологии. Если в самом `.ont` есть сокращение, приложение не восстанавливает недостающую информацию.
2. **Сессия не привязана к единственному следующему элементу DFS.** После вопроса текущим становится понятие, о котором пользователь спросил, а не следующий узел в заранее рассчитанном обходе.
3. **Переходы в обе стороны по всем связям.** После выбора понятия пользователь может спросить о любом его соседе, в том числе родителе (`is_a`), частях (`has` / `a_part_of`), боковых связях или вернуться к ранее изученному узлу. Можно задать вопрос и о другом понятии в доступной области (переход к другой теме); он будет засчитан.
4. **Неизвестные типы отношений не блокируют навигацию.** Название и направление связи берутся из ONTOLIS. Для содержательного объяснения нестандартного отношения по-прежнему полезно задать его учебную роль в настройках.
5. **Настройка глубины ограничивает число переходов от выбранных тем.** `0` — вся связная компонента выбранных тем, `1`, `2`, `3` — соответствующий радиус по любым направленным рёбрам (для достижения соседа используются оба направления). Это ограничение области обучения, а не порядка вопросов.
6. **Строка состояния и подсказки теперь показывают последнее изученное понятие.** Предлагаются вопросы о соседях, ещё не пройденные — первыми. Визуальный дизайн сохранён.
7. **История сессии хранит фактическую последовательность запросов.** Если пользователь спросил сначала о Синапсе, затем о Математической модели, именно эти переходы сохраняются и восстанавливаются после обновления страницы, пока сервер не перезапущен.

## Пример

Начните занятие с понятием «Искусственная нейронная сеть» и вопросом `Как работает ИНС?`. После ответа можно спросить `Что такое математическая модель?`, `Что такое слой нейронов?`, `Что такое синапс?`, `Что такое нейрон?` и вернуться к ИНС. Порядок произвольный. Это лишь пример проверки; правила не содержат определений или списков допустимых переходов, привязанных к данной предметной области.

## Что осталось неизменным

- Индексация названий/определений, морфологический, нечёткий и TF-IDF-поиск из V7.
- Ответы на основе направленных семантических троек ONTOLIS.
- Формат ответа: **вопрос → определение → объяснение**.
- Граф и уровни его отображения (1/2/3/«Все»).
- Количество вопросов, категории запросов и досрочное завершение занятия.
- Отсутствие генеративной LLM в процессе ответа.

## Обновление без потери своей онтологии

Если у вас установлена **версия 7**, скачайте архив `OntoTutor_v8_code_only_patch.zip` и замените в папке `ontolis_tutor` файлы согласно структуре архива. Папку `data/` **не заменяйте и не удаляйте**. При этом активные сессии из памяти сервера после его перезапуска потеряются, но файлы онтологий сохранятся.

Если устанавливаете с нуля, скачайте полный архив, распакуйте, запустите `start_windows.bat` либо выполните `python -m uvicorn app:app --reload` из папки `ontolis_tutor` в окружении с установленными зависимостями из `requirements.txt`.

## API и состояние

- `POST /api/sessions/{sid}/ask`: ответ по запрошенному понятию, `transition` (`start`, `neighbor`, `return`, `follow_up`, `topic_change`), фактическое `traversed_via` для соседней стрелки.
- `GET /api/sessions/{sid}`: `current` — последнее понятие, `neighbors` — все соседние понятия в разрешённой области, `next` — их упрощённый список, `explored_count` — число различных изученных понятий.
- `result=out_of_scope` возвращается при выходе за границу установленной области/глубины; такой вопрос не засчитывается.
- `branch_completed=true` означает, что просмотрены все понятия разрешённой области, а не завершён один жёстко определённый DFS-маршрут.

## Проверки и ограничения

Протестированы исходная онтология и посторонняя синтетическая предметная область. Команда: `python -m pytest -q` — **53 passed** в данном наборе. Новые тесты проверяют полноту длинного определения, переходы в обе стороны, выбор соседней ветки и ограничение глубины.

Для совершенно произвольных онтологий поиск по естественному языку остаётся вероятностным: если термин не распознан однозначно, система предлагает кандидатов. Неизвестные отношения можно показывать и проходить, но для точного содержательного ответа об их смысле следует определить учебную роль или явно описать семантику в онтологии.
